# The Bratanic Adventure

A 3D game about a big ocean liner, the Bratanic, and its little submarine, designed by a young ship builder.
Made for family and friends. Current version: **2.0.0**

## Install on Windows

1. Download the Setup file and open it. If your browser asks whether to keep the file, choose **Keep**.
2. Windows may show a blue box: "Windows protected your PC". This happens because the game is not "signed" yet
   (signing costs money every year). Click **More info**, then **Run anyway**.
3. The game installs by itself in a few seconds and starts. You will find it on the desktop and in the Start menu.

**Updates:** the game downloads new versions by itself while you play. When one is ready, a small message says so.
It is installed when you close the game, or straight away if you click **Update now**.

## Install on Mac

1. Download the .dmg file for your Mac and open it.
2. Drag **The Bratanic Adventure** onto the **Applications** folder.
3. The first time only, because the game is not signed by Apple yet:
   - open the Applications folder, **right-click** (or Control-click) the game, choose **Open**, then **Open** again.
   - On newer macOS versions (15 Sequoia and later) there may be no Open button. Then click **Done**, open
     **System Settings**, go to **Privacy & Security**, scroll down, click **Open Anyway** next to
     The Bratanic Adventure, and confirm with your password.
4. After that, the game opens normally.

**Updates:** when a new version exists, the game shows **Download the new version**. Quit the game, download the new
.dmg, drag the game to Applications again and choose **Replace**. Your progress stays. You may need to do step 3 again.

## Your progress

Progress is saved on your computer and stays when you update the game.
Windows: in `%APPDATA%\The Bratanic Adventure`. Mac: in `~/Library/Application Support/The Bratanic Adventure`.
